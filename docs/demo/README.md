# Local demo evidence

`orby-simulation-walkthrough.webm` records the actual local UI: job creation, execution plan, failed-child rehearsal, counteroffer, explicit escrow funding, delivery, settlement and private/redacted receipt export. It is an automated simulation walkthrough, without audio, not an on-chain execution recording. Play it locally in a browser or video player.

The PNGs show desktop, 390px mobile, dark theme, quality, knowledge, teams and an actual verified testnet receipt. Separate JSON reports in the parent directory contain real testnet transaction evidence. No private key or Google token appears in these artifacts. Public hosting and X publication are pending owner publication.
