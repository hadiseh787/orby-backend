| مهم ۲: بید legacy | دیالوگ واحد کار را تشخیص می‌دهد؛ NEAR با ۲۴ و USD قدیمی با ۶ رقم تبدیل می‌شود. مبلغ legacy صریحاً USD نشان داده می‌شود؛ تبدیل نمایشی با نرخ ثابت حذف شد. Agent صرفاً بومی از گزینه‌های بید USD کنار می‌رود و API نیز آن را رد می‌کند. |

UNKNOWN یا SUBMITTED نیازمند تطبیق رسید است. Agent تأییدشده با مالک و هش منیفست مطابق از قرارداد بازیابی می‌شود. |

| جزئی ۱۲: teardown | worker پیش از بستن app و pool تخلیه می‌شود؛ حذف دیتابیس پس از بسته شدن اتصال‌ها بدون FORCE انجام می‌شود تا اتصال در حال استفاده قطع نشود. |

سایر بهبودهای داک نیز اعمال شد: CSP با nonce فعال شد، عمر preview در بک‌اند و قرارداد ۵ دقیقه شد، نام ورودی لاگین `accountId` است و دو کار نمونهٔ واقعیِ شبیه‌سازی، یکی OPEN بومی و یکی SETTLED، به seed تکرارپذیر اضافه شد. نمونهٔ تسویه‌شده از همان مسیر مالی برنامه عبور می‌کند و تراکنش تست‌نت نمی‌سازد. برای شکستن تدریجی فایل‌ها، منطق امنیت و بازیابی ثبت Agent، seed نمونه‌ها و نمایش مبلغ قرارداد به ماژول‌های مستقل منتقل شدند؛ بازنویسی کامل ساختار برنامه انجام نشد.

تست نهایی موبایل تداخل CSP با inline critical CSS تولیدشدهٔ Angular را پیدا کرد. این بهینه‌سازی، CSS را با `media=print` و handler درون‌خطی onload بارگذاری می‌کرد که CSP مسدود می‌کند. در بیلد production، inlineCritical غیرفعال شد؛ minify حفظ شده و CSS کامل بدون handler درون‌خطی بارگذاری می‌شود. تست CSP نبود onload و اعمال شدن استایل واقعی را نیز بررسی می‌کند.

## اعتبارسنجی

- بیلد Angular و TypeScript بک‌اند موفق است.
- ۱۰ تست واحد/Runtime، شامل ۱۰٬۰۰۰ حالت حفظ موجودی و تازگی هر دو منبع قیمت، موفق است.
- ۱۲ تست یکپارچهٔ PostgreSQL شامل بازیابی ثبت، مرز احراز هویت، بید USD و سهمیهٔ آپلود موفق است؛ اجرای متوالی بدون خطای teardown بررسی شد.
- ۱۰ تست مرورگر شامل CSP، چرخش nonce، اجرای sandbox کیف پول با RPC و ارسال واقعی USD از دیالوگ به API است.
- سه تست مالی Rust موفق است و WASM بهینه با تنظیمات سازگار NEAR ساخته شد.
- ارتقای قرارداد تست‌نت بدون ساخت حساب، seed یا تغییر چیدمان state انجام شد. مقایسهٔ قبل/بعد همهٔ ۷ کار و ۸ موجودی قرارداد را بدون تغییر تأیید کرد: `orby-upgrade-20261107.json`.
- گردش واقعی مرورگر تا تست‌نت با CSP فعال پاس شد: ثبت Agent، ورود NEP-413، policy و bond، ساخت کار و پیوست، بید مالک، تغییر قیمت بدون تغییر نسخهٔ منیفست، فاند بید قبلی با preview پنج‌دقیقه‌ای، تحویل، ارزیابی، تأیید، تسویه و برداشت موفق. کار `48292f93-d26f-4186-9525-fb3de9333093` به SETTLED رسید؛ award برابر ۰٫۱، refund برابر ۰٫۰۱، fee برابر ۰٫۰۱ و اعتبار سازنده برابر ۰٫۰۹ NEAR تستی بود. رسیدها در `orby-browser-testnet.json` هستند.
- backup پس از مایگریشن جدید روی دیتابیس تازه restore شد؛ جدول‌ها، پیوست‌ها، hashها و تعداد ردیف‌ها تأیید شدند.

## محدودهٔ تحویل

مین‌نت فعال نیست. تست کیف پول توسعه از امضای واقعی و تراکنش واقعی تست‌نت استفاده می‌کند؛ تأیید شخصی در تمام کیف پول‌های ثالث تست نشده است. مدل Ollama و IPFS عمومیِ دائمی همچنان تنظیمات استقرار جداگانه می‌خواهند. CSP برای سازگاری کیف پول اجازهٔ HTTPS/WSS و inline style دارد؛ ممیزی مستقل امنیتی محسوب نمی‌شود. هیچ تستی تضمین نبود تمام باگ‌های ناشناخته نیست.
