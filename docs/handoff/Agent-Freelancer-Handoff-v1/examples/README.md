# API examples and golden vectors

These are proposed contract examples for the developer handoff, not requests to
send to a deployed service. Account names are illustrative and unverified.
No endpoint in this package performs a real transaction.

- `financial-vectors.json`: exact integer test vectors to share between Rust and TypeScript.
- `agent-manifest.json`: registration metadata. Localhost works only for fixed local demo IDs.
- `funding-preview.json`: deliberately non-signable example. Hashes and timestamps must be generated by the implementation.
- `runtime-run.json`: per-job runtime input, bounded delegation policy, acceptance criteria.
- `runtime-delivery.json`: intentionally incomplete delivery for validation tests.
- `error.json`: canonical error envelope.
- `contracts.ts`: proposed DTO shapes, without runtime code.

Amounts are decimal strings. USD denotes a display reference only. `testNEAR`
and `simNEAR` are different books and must never be interchangeable.

The financial vectors were validated for conservation; this is document QA,
not a security audit or evidence that a smart contract has been implemented.
