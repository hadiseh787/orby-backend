# Orby 1.3 — اجرای گزارش Review and Roadmap v2

دامنهٔ این نسخه شش ایراد گزارش و هر شش قابلیت برنامهٔ توسعه است. متن ورودی در `review-v2/` نگهداری می‌شود؛ امتیاز گزارش قبلی نتیجهٔ ارزیابی این نسخه نیست. رابط محصول انگلیسی است. اجرای محلی همچنان از پوشهٔ backend با `npm run local` یا `start-local.cmd` انجام می‌شود و PostgreSQL، API، worker و Angular با هم بالا می‌آیند.

## اصلاح شش ایراد

| مورد | تغییر | شاهد قابل بازتولید |
|---|---|---|
| ذخیره‌سازی قرارداد و پشتوانهٔ مطالبات | مجموعه‌های indexed نسخهٔ ۳، شمارندهٔ بدهی به کاربران، بودجهٔ مستقل sponsor، محدودیت رشته‌ها و ورودی‌ها، ذخیرهٔ خروج برای تعهدات فعال؛ سابقهٔ idempotency پاک نمی‌شود | تست‌های رفتاری Rust؛ مهاجرت واقعی در `orby-v3-upgrade.json`؛ آزمون WASM/RPC در `orby-v3-load.json` |
| حذف دانش در واگذاری | سازندهٔ مشترک ورودی، snapshot ثابت، حفظ دانش اصلی پس از دریافت نتیجهٔ فرزند، ارسال دانش به فرزند فقط با مجوز صریح | تست محصول با runtime HTTP کنترل‌شده؛ تست مرورگرِ مجوز هر مرحله |
| پرداخت فرزند مردود | بررسی‌های الزامی دروازهٔ تسویه‌اند؛ شکست به اصلاح و سپس اختلاف می‌رود؛ والد هم خروجی مردود را مصرف نمی‌کند | تست پرداخت صفر در شکست و پرداخت دقیقاً یک بار پس از اصلاح |
| تأیید بدون نسخه | قرارداد جدید فقط `approve_delivery` با revision و hash دقیق؛ `approve_job` محدود به سفارش legacy | تست نقش، نسخه، replay و مسیر قدیمی قرارداد؛ تست API و مرورگر تست‌نت |
| بازیابی Sheets خارج محدوده | ثبت قصد نوشتن پیش از تماس خارجی، نشانگر پایدار، جست‌وجوی صفحه‌بندی‌شده بیرون از محدودهٔ ردیف اولیه؛ وضعیت نامطمئن مانع نوشتن دوباره است | سرویس HTTP کنترل‌شده با پاسخ گم‌شده و شروع مجدد API؛ بدون ردیف تکراری |
| تغییر ساعت رسمی | زمان ناموجود بهار رد نمی‌شود و به نوبت معتبر بعدی می‌رود؛ ساعت تکراری پاییز فقط اولین بار اجرا می‌شود؛ منطقهٔ زمانی نامعتبر خطای ورودی می‌دهد | تست زمان عادی، DST، عبور ماه و چند منطقهٔ زمانی |

بودجهٔ sponsor هزینهٔ زیرساخت قرارداد است و از موجودی کاربران کم نمی‌شود. در تست‌نت برای هر حساب دارای مطالبه ۰٫۱ و برای هر escrow فعال ۰٫۳ NEAR برای خروج رزرو می‌شود. رشد جدید اجازهٔ مصرف این ذخیره را ندارد. callback برداشت ۵۰ TGas دریافت می‌کند. این اعداد محدودیت عملیاتی نسخهٔ فعلی‌اند و ادعای مقیاس نامحدود نیستند. مدیر باید بودجهٔ sponsor را پایش کند؛ کمبود آن ایجاد تعهد جدید را متوقف می‌کند.

## اجرای آزمون‌ها

از backend: `npm test`، `npm run test:integration`، `npm run contract:test` و `npm run build`.

از frontend: `npm run build` و سپس `PLAYWRIGHT_BASE_URL` متناسب با نشانی launcher و `npm run test:e2e`. آزمون مرورگر به API و worker در حال اجرا نیاز دارد؛ محدودیت نرخ API غیرفعال نمی‌شود. ابزار axe نیز معیارهای WCAG 2 A/AA و 2.1 AA را روی مسیرهای جدید در دسکتاپ و موبایل بررسی می‌کند.

آزمون‌های زنجیره اختیاری‌اند و کلید توسعهٔ نادیده‌گرفته‌شده در Git نیاز دارند: `npm run test:browser:testnet`، `npm run near:smoke` و `node --import tsx tests/contract-load-testnet.ts --run`. آزمون بار، حساب موقت جدا می‌سازد و فقط پس از صفر شدن مطالبات آن را می‌بندد. روی mainnet اجرا نمی‌شود.

مهاجرت واقعی تمام ورودی‌های هر ۹ map نسخهٔ قبلی را decode و بعد از ارتقا با نماهای قرارداد مقایسه کرد: ۹ ایجنت، ۹ policy، ۱۰ سفارش، ۱۲ پیشنهاد، ۵ موجودی، ۱۰۴ سابقهٔ عملیات، ۴ برداشت و mapهای native. مقدار کل مطالبات دقیقاً حفظ شد. فایل شامل کلید یا snapshot خصوصی در مخزن قرار نمی‌گیرد.

## محدودیت‌های گزارش‌شده

این نسخه ممیزی مستقل امنیتی یا تضمین نبود تمام باگ‌ها نیست. اجرای زندهٔ حساب Google، مدل واقعی Ollama و امضای انسانی با HOT/Meteor با تست HTTP یا کیف پول توسعه یکسان نیستند. تست‌های خودکار این تفاوت را در گزارش‌ها مشخص می‌کنند. PostgreSQL و استقرار پاک روی Windows x64 بررسی می‌شوند؛ Linux/macOS نیازمند اجرای مستقل‌اند.

وابستگی High مربوط به `@fastify/static` ارتقا یافته است. خلاصهٔ audit تازه در `DEPENDENCY_REVIEW.md` ثبت می‌شود؛ خروجی audit به‌تنهایی اثبات بهره‌برداری در این محصول نیست. هش و رسید زنجیره صحت محتوای تولیدشده را اثبات نمی‌کنند.

مخزن‌ها مطابق درخواست قبلی خصوصی می‌مانند. LICENSE کد، شواهد، ویدئوی محلی و متن پیش‌نویس ارسال آماده می‌شوند. عمومی‌کردن مخزن‌ها و انتشار پست X انجام نمی‌شود؛ این‌ها اقدامات انتشار بیرونی‌اند و با ترجیح ثبت‌شدهٔ مخزن خصوصی تعارض دارند.
